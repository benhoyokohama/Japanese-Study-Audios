二、 课件制作标准流水线（半自动化）

[MP3 音频] ➔ Whisper 本地声波切片 (.srt) ➔ Python 注入假名/语法/词汇 (.json) ➔ 注册 index.html ➔ Git Push 上线

  1. 音频归档：录音统一转换为 2026-xxx.mp3 存放在 lessons/ 目录。
  2. Whisper 物理切片：终端运行 whisper lessons/2026-xxx.mp3 --language Japanese --model small --output_format srt --output_dir . 提取精准毫秒级声学时间戳。
  3. JSON 课件增强：脚本将 SRT 转换为带 <ruby> 汉字注音、中文翻译，以及每句专属语法考点与 N4+ 词汇的 lessons/2026-xxx.json。
  4. 挂载与发布：在 index.html 添加 <option> 选项，执行 git push origin main 即可全球 CDN 秒级生效。

三、 播放器核心引擎技术规范

  • 切句与防卡死机制：同时监听 ontimeupdate 与 onended 事件，彻底解决移动端音频尾帧卡死问题。
  • 三模循环状态机：单句循环（🔂）、本课列表循环（🔁）、跨课顺序播放（➡️）。
  • 高精度倒计时：独立秒级倒计时徽标，不受播放或切句打扰，到时自动暂停复位。
